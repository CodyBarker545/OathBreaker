# References

`Terrain3D/` preserves the separately downloaded Terrain3D add-on and demo from the former `oath-breaker/` folder. No demo scenes or original assets were discarded. Its original project settings are stored as `project.godot.reference` and `.gdignore` excludes the reference from active game imports.

The active game is the root `project.godot`; its level editor opens `Scenes/Battlefield.tscn`. Terrain3D is installed under `addons/terrain_3d` and enabled in the game. The root `demo/` retains the original example resource paths.
