# Wooden tavern chair

Original chair model created in Blender for Oathbreakers.

- Editable source: `wooden_chair.blend` (36 separate mesh pieces; studio collection is for presentation only).
- Game export: `Assets/Levels/Props/wooden_chair.glb` from the repository root.
- Preview: `wooden_chair_preview.png`.
- Three packed 512px oak colour textures are included in the blend and GLB, with PNG source copies here.
- Dimensions: approximately 0.62m wide, 0.62m deep and 1.21m tall. The GLB uses Godot-compatible axes.

Drag the GLB into `LevelProps` in the Godot level. The model has no built-in interaction or collision.
