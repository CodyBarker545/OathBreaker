# Ashveil source model

Stylized interpretation of the user-supplied Ashveil ninja reference, using the fitted Eliber base body and shared animation skeleton. Runtime model: `Assets/Characters/Ashveil/Ashveil.glb`.

Source body: Rigged Base Mesh by Eliber, https://blendswap.com/blend/14675, CC0, including the creator's licensing clarification. The original download and licence are preserved in `SourceAssets/characters/_base/`.

`ashveil.blend` contains editable outfit parts, body, rig, materials and animation actions. `ashveil.glb` is its game export. `ashveil_preview.png` is a Blender render. The old Python build script was removed during the C# migration; edit the Blender scene and export GLB directly.

Idle, Walk and Arm_Motion_Test clips are included. This remains a stylized prototype with draft animation and cloth weighting. Weapons and smoke/teleport gameplay are not implemented.
