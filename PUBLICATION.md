## Setup and use

Install the Godot .NET editor version declared by the project and its required .NET SDK. Import `project.godot`, allow assets to import, then run the main scene.

## Data and configuration

Keep input data at the relative paths referenced by the source, or update those paths for your environment. Configure service endpoints and credentials locally when required. Generated caches, dependency folders, local credentials, and files beyond GitHub's normal upload limit are omitted from this snapshot.
